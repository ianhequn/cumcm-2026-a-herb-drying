# CUMCM 2026 A — 药材热风烘干热质耦合模型

2026 年全国大学生数学建模竞赛 A 题参赛项目 这就是原汁原味的提交工作区 除了个人信息一丝不改 最后是广东省二 可以为所有数模er参考 来自广东工业大学信息工程学院

本项目面向药材热风烘干过程，建立一维轴对称热—质耦合输运模型，对预热、变物性干燥、阈值首达时刻与收缩动边界四个问题进行数值求解与验证。

## 核心工作

- 采用节点中心有限体积、后向 Euler 时间离散和 Picard 迭代求解热—质耦合方程；
- 以 Bessel--Duhamel 解析解、守恒残差、网格/时间步收敛性和灵敏度分析验证数值结果；
- 用干质量拉格朗日坐标处理收缩动边界，并以消融实验分解物性、收缩及交互效应；
- 提供论文终稿、完整求解代码、图表、配置文件及问题一至问题四的结果表。

## 关键结果

- 问题一解析解校验的最大温度偏差为 \(5.224\times10^{-4}\) °C；
- 问题三得到烘干时长为 57.4247 h；
- 问题四引入收缩动边界后，烘干时长为 51.0711 h；
- 全程离散守恒残差为 \(3.425\times10^{-10}\)。

## 快速复现

建议使用 Python 3.10 或更高版本：

```bash
pip install -r requirements.txt
python code/main.py
```

可分别运行 `code/problem1.py` 至 `code/problem4.py`。程序采用相对路径，请保持仓库目录结构不变。
